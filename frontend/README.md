# ApproveDesk frontend

Next.js App Router + TypeScript + Tailwind CSS starter. The current home page is only the project scaffold; Member 4 owns the institution portal and Member 5 owns the officer/admin UI plus shared API helper/types.

```powershell
Copy-Item .env.example .env.local
npm install
npm run dev
```

Set `NEXT_PUBLIC_API_BASE_URL` to the local FastAPI API base (`http://localhost:8000/api`).
